# FrameScratch

Turn any video into a Scratch costume pack, right in your browser.

Upload a video, trim and adjust it, and download a ZIP of frames ready to import into Scratch as costumes. FrameScratch also shows you the exact blocks to animate them at the right speed.

**Repo:** https://github.com/malindidev/FrameScratch

**Live:** https://frame.bbnerds.com

## Features

- Runs entirely in your browser, no video is uploaded anywhere
- Trim, resize, and export as PNG or JPEG
- Auto-generated Scratch block stack for correct animation speed

## Local development

```bash
npm install
npm run dev
```
